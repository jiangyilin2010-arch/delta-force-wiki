## 部署

文件可直接用于静态托管。GitHub Settings → Pages 使用 main 分支的根目录。
首页为 index.html，无需安装依赖或构建。不要把原站的托管配置或密钥上传至本仓库。

## 存档与账号

小游戏主要使用当前浏览器的本地存储。两个网址的存档互不共享，也不会自动迁移。
GitHub Pages 不提供服务端 API，停车场玩法的档案在镜像中使用本地模式，
不支持云同步、跨设备账号或真实玩家之间的云端赠礼。
