## English

**Asala Fun Lab** is an unofficial **Delta Force fan-made browser game collection** and community wiki.

Featured games include **Haff Currency War**, a single-player PvE tactical autobattler inspired by Honkai: Star Rail's Currency Wars, plus tile matching, a randomized extraction story simulator, and minesweeper. The games are primarily in Simplified Chinese.

[Play in your browser](https://jiangyilin2010-arch.github.io/delta-force-wiki/mini_games.html). No game-client download required. This is a work in progress, not an official Delta Force or Honkai: Star Rail product.

## 存档与账号

小游戏主要使用当前浏览器的本地存储。两个网址的存档互不共享，也不会自动迁移。
GitHub Pages 不提供服务端 API，停车场玩法的档案在镜像中使用本地模式，
不支持云同步、跨设备账号或真实玩家之间的云端赠礼。
